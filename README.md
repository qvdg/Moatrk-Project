# Motark Project 🚗 🤖

An innovative AI-powered platform designed to identify car spare parts from images and manage price quotations (Bids).

## 🚀 Technologies Used
- **Frontend:** Next.js, React, Tailwind CSS.
- **AI Integration:** Image Analysis Model.
- **Version Control:** GitHub.

## 🛠️ Main Features
- Automated part detection using AI.
- Real-time bidding system for suppliers.
- User-friendly dashboard for car owners.
